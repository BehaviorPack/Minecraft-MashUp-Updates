## Change Files

Each `data/changes/{pack-name}-{version}.json` file contains:

```json
{
  "pack": "LittleBigPlanet Mash-up",
  "version": "1.0.75",
  "added": ["textures/foo.png"],
  "removed": [],
  "engine": "1.21.0",
  "icon_url": "https://.../packicon_0.jpg",
  "thumbnail_url": "https://.../Thumbnail_0.jpg"
}
```

## How it works

1. GitHub Action runs every 24 hours
2. Authenticates with PlayFab using repository secrets
3. Fetches each tracked UUID from the catalog
4. Compares ETag + version to last run
5. If changed: downloads `primary.zip`, extracts, diffs file list
6. Writes `data/changes/{pack}-{ver}.json` and updates this README
7. Commits everything back to the repo
